# AntiScreenSaver

這是一個用來防止 Windows 系統進入螢幕保護程式或休眠狀態的工具集。提供終端機 PowerShell 腳本版本與免安裝純網頁（HTML）版本。

## 方案介紹

### 方案一：PowerShell 終端腳本 (`AntiScreenSaver.ps1`)
- **特色**：提供互動式終端機選單，定期模擬滑鼠微動以防休眠。
- **環境需求**：Windows、PowerShell 7+ (`pwsh`)。
- **執行方式**：
  ```powershell
  .\AntiScreenSaver.ps1
  ```
- **操作說明**：依照終端機顯示的選單輸入數字進行操作（輸入 `1` 啟動，按鍵盤 `Q` 鍵停止；輸入 `2` 結束）。

---

### 方案二：免安裝純網頁喚醒版 (`KeepAwake.html`)【防毒軟體／防火牆相容方案】
- **特色**：專為公司嚴格資安環境設計。若公司防火牆或端點安全防護軟體（EDR、防毒軟體）封鎖 `.ps1` 檔案、阻擋可疑捷徑或限制 PowerShell 腳本執行原則，可直接使用此純網頁版本。
- **運作原理**：
  - 採用 W3C 標準 **Screen Wake Lock API**，直接通知作業系統維持顯示與喚醒狀態。
  - 內嵌靜音媒體循環雙重備援機制，兼具最高相容性。
  - 完全無可執行二進位程式碼或腳本後門，100% 不會被防毒軟體誤判或攔截。
- **執行方式**：
  - 直接以任何現代瀏覽器（Microsoft Edge、Google Chrome）雙擊開啟 `KeepAwake.html`。
  - 保持該分頁開啟（在背景或縮小皆可），即可防止螢幕保護程式與休眠。
  - 介面提供實時清醒計時器與「暫停 / 恢復」按鈕。
